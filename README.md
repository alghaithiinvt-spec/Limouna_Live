# ليمونة لايف 🍋

تطبيق دردشة وتعارف وبث مباشر (Flutter).

## التشغيل
```bash
flutter create . --platforms=android,ios
flutter pub get
flutter run
```

## الرفع على GitHub
```bash
git init && git add . && git commit -m "init"
git branch -M main
git remote add origin https://github.com/USERNAME/lemona-live.git
git push -u origin main
```
بعد الرفع يبني GitHub Actions ملف APK تلقائياً (تبويب Actions).
